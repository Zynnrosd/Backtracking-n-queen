# N-Queens Backtracking (Python)

Program ini adalah implementasi algoritma Backtracking untuk menyelesaikan N-Queens Problem menggunakan Python. Dilengkapi dengan visualisasi berbasis CLI untuk melihat langkah-langkah penempatan ratu dan proses *backtrack*. Dibuat untuk memenuhi tugas mata kuliah Algoritma / Struktur Data.

## Cara Menjalankan

1. Pastikan Python 3 sudah terinstal di komputer Anda.
2. Buka terminal atau *command prompt*, lalu jalankan perintah berikut:
   ```bash
   python n_queens_backtracking.py
Masukkan ukuran papan/jumlah Queen saat diminta (disarankan N = 4 untuk visualisasi yang optimal).
